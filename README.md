# 교안 자동 생성기

## 무엇을 하는 서비스인가

강의 주제를 넣으면 교안만 보고 수업을 진행할 수 있을 만큼 상세한 교안과, 수강생이 몇 칸만 채우면 완성 프롬프트가 나오는 실습용 아티팩트(프롬프트 생성기)를 함께 만들어 주는 강사용 도구입니다. 만들기 전에 지금까지 만든 교안·강의 기록과 겹치는지 먼저 보여 주고, 만든 교안과 아티팩트는 따로 목록에 모아 오픈채팅방에 붙여 넣을 링크 글로 만들어 줍니다. 아티팩트를 잠그면 수강생 화면에서 프롬프트를 만들 수 없습니다.

주 5일 강의를 혼자 준비하다 보니 전날 밤에 교안을 붙잡고 있는 날이 많아서 만들었습니다.

## 누구를 위한 것인가

AI 수업을 혼자 진행하는 오프라인 AI 강사를 위한 도구입니다.

- 주 5일 수업이라 매번 새 주제를 준비해야 하는 강사
- 수강생이 AI에 어느 정도 익숙한 시니어 학습자라, 기초 반복보다 새로운 활용을 다뤄야 하는 수업
- 설명과 개별 실습을 섞어 진행하고, 수업 중에 수강생이 링크로 실습 화면을 열어 쓰는 방식

수강생은 강사가 공유한 링크로 교안이나 아티팩트를 열어 보기만 합니다. 수강생이 따로 가입하거나 접속 관리를 하지는 않습니다.

## 어떻게 쓰나

1. **첫 화면** — 시작하기를 눌러 들어갑니다.
2. **주제 입력** — 강의 주제·수강생 수준·수업 시간을 넣고 만들기를 누릅니다.
3. **기존 자료 확인** — 겹치는 교안을 확인하고, 기존 교안을 열거나 새로 생성합니다.
4. **교안 및 아티팩트** — 교안을 읽고 내려받고, 아티팩트를 확인하고 잠그거나 풉니다.
5. **프롬프트 생성기** — 조건을 넣어 완성 프롬프트를 만들고 복사합니다.
6. **저장된 목록** — 교안·아티팩트를 따로 보고, 오픈채팅방 공유 글을 만들고, 아티팩트를 잠그거나 풉니다.

**그 밖에**
- 왼쪽 메뉴에서 화면 사이를 오가고, 수강생 화면을 미리 봅니다 (잠긴 아티팩트는 프롬프트 만들기가 막힙니다).
- 한 줄 방명록과 AI 기록(날짜별로 보기)도 왼쪽 메뉴에서 엽니다.
- 오른쪽 아래 고양이 버튼은 문의 글에 말투를 골라 답변 초안을 써 주는 상담 챗봇입니다.
