# IPO 정리

한 줄 : 강의 주제를 넣으면, 교안과 아티팩트가 나온다.

1. 입력 : 강의 주제
2. 처리 : 주제에 맞는 설명·실습 교안과 아티팩트를 만든다
3. 출력 후보 3개 :
   - 상세한 교안이 설명 화면과 실습 화면으로 나뉘어, 실습 개수만큼 여러 개가 순서대로 이어서 나온다
   - 교안 카드와 아티팩트 카드가 각각 하나씩 생겨서 목록에 두 개가 나란히 쌓이고, 아티팩트 카드에는 잠금 버튼이 붙어 있다
   - 완성된 아티팩트 링크 하나가 나오고, 강사가 그 링크를 눌러 공유하거나 잠글 수 있다
4. 모양 : 만들어주는 도구 — 주제를 넣을 때마다 그 자리에서 새 교안·아티팩트가 생겨나는 것이라 "모아 보여주는 화면"이나 "소개하는 페이지"보다 여기에 가장 가깝다.
