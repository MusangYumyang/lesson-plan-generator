# 내가 겪는 불편

1. 작업물이 다음 대화로 안 넘어옴- 전 세션에서 만든 대화 내용을 못 받거나 이어서 만들때 처음부터 다시 설명 *****
2.  대량 생성 실패- 파트가 많으면 생성이 조용히 죽어서 직접 생성으로 방식을 바꿈
3. 설명이 추상적으로 나오고 구체적으로 안나옴- 설정-> 디스플레이-> 잠금화면 처럼 실제 클릭 경로 단위로 다시 써달라고 요청한 적이 여러번 있음 ****
4. 수강생 지칭, 프레이밍 수정- 어르신이나 손주언급, 가족 역할 중심 서술이 계속 섞여 나와 매번 빼야했음, 요즘은 개인 사회라 이런 용어는 지양 **
5. 개별 실습 원칙으로 짝꿍이나 조별 활동 실습은 지양 
6. 실제 앱, 스크린샷을 못 넣음- 작업 환경 네트워크 제한 때문에 아이콘, 색상 블록으로 대체하고, 사진은 따로 넣어야하거나 작업을 두번 세번 여러번 해야하는 번거로움이 심했음 *
7. 이미 다룬 주제와 여러번 겹치는지 확인-최근 어떤 주제를 다루었는지 확인해야한다. 수업이 주ㅡ5일이다보니 아무래도 수업이 겹칠 수 있음. 그러면 수업의 내용을 꼬거나 재미있는 주제로 항상 새롭게 진행해야한다. **
8. 산출물 형식을 매번 다시 정해야함. 
9. 수강생 수준에 안맞는 너무 기초적인 수준의 내용이 섞임. AI란 무엇인가 같은 입문 내용이 첫 아웃라인에 들어와 걷어내야함 **
10. 보조강사들이 수업난이도가 어렵다고 말한다 ***
