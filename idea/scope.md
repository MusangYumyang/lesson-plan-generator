# 만들 범위

## 넣을 기능

1. 주제를 넣으면 주제마다 설명과 실습에 대한 교안이 이미지와 함께 생긴다, 아티팩트도 함께 생성 (핵심)
2. 아티팩트도 생성되면 좋다. 프롬프트 생성기같은 것
3. 교안과 아티팩트는 따로 생성되서 분류해두면 강사가 따로 오픈채팅방에 링크를 공유해서 수업을 진행
4. 만든 아티팩트를 강사가 잠그는 기능
5. 강의 주제를 넣으면, 기존에 만든 교안·강의 내역을 전부 스캔해서 겹치는 강의가 있는지 확인하고, 있으면 기존 교안을 보여주고 새로 만들기도 할 수 있다
6. 여러 강사가 각자 로그인해서 계정을 따로 쓴다
7. 받은 문의 글을 넣으면 강사가 고쳐 보낼 수 있는 답변 초안을 만들어 준다 — 화면 오른쪽 아래 미니 상담 챗봇으로 (Gemini 사용, 대화는 저장하지 않음)
8. 수강생용 자료방 — 강사가 수강생에게 줄 교재자료를 주제(카테고리)별로 올려 두고, 수강생은 링크로 들어와 보고 내려받는다. 강사용 교안과는 다른 자료다.
9. 수강생용 결과물방 — 수강생이 자기 실습 결과물을 올리고 서로 본다. 강사는 지우거나 숨길 수 있다.

## 만들 때 지킬 것

- pc에서도 열리고 모바일에서도 쉽게 열리는 구조로 만들어야한다.
- 교안은 한 장 요약이 아니라, 그것만 보고 수업을 진행할 수 있을 만큼 상세하게 나와야한다.

## 뺄 기능

- 학생이 결제한다 (수강생이 자료방·결과물방에 직접 들어오는 것은 넣을 기능 8·9 로 들어감 — 2026-11-10)
- 만든 교안을 다른 강사와 실시간으로 같이 편집한다
- 만든 교안과 아티팩트를 자동으로 이메일이나 문자로 발송한다

## 한 번 써 보는 순서

1. 강사가 다음 수업 주제를 입력한다
2. 만들기를 누르면 주제에 맞는 교안이 설명·실습 내용과 이미지로 생긴다
3. 같이 생성된 아티팩트(실습용 화면·문서)도 확인한다
4. 교안과 아티팩트가 따로 정리되어 목록에 쌓인다
5. 강사가 오픈채팅방에 아티팩트 링크를 공유해 수업을 진행한다
